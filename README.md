# IceHop Privacy Policy

Hosts the privacy policy for the IceHop iOS app, served as a public document so the App Store listing can link to it.

The policy itself lives in [`privacy-policy.md`](privacy-policy.md).

## Why a dedicated repo

The App Store review requires a public, persistent URL to the privacy policy. A standalone GitHub repository gives a stable raw/file URL without needing to maintain a separate website.
